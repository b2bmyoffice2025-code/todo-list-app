# Todo List Application 📝

A modern, responsive to-do list application with local storage functionality. Manage your tasks efficiently with a beautiful and user-friendly interface.

## ✨ Features

### Core Functionality
- ✅ **Add Tasks** - Quickly add new tasks with a simple input field
- 🗑️ **Delete Tasks** - Remove tasks you no longer need
- ✔️ **Mark as Complete** - Check off tasks as you complete them
- 🎯 **Filter Tasks** - View all, active, or completed tasks
- 💾 **Local Storage** - All tasks are automatically saved to your device
- 📊 **Statistics** - Track total, completed, and pending tasks

### User Interface
- 🎨 Beautiful gradient design with purple theme
- 📱 Fully responsive for mobile, tablet, and desktop
- ⚡ Smooth animations and transitions
- 🎭 Interactive elements with hover effects
- 🌟 Clean and intuitive layout

### Additional Features
- 📅 Task creation date tracking
- 🔄 Real-time statistics updates
- 🧹 Clear all completed tasks with one click
- ⌨️ Keyboard support (Enter key to add tasks)
- 📧 Task validation (no empty tasks, max 100 characters)

## 🚀 How to Use

### Installation
1. Clone or download the repository
2. Open `index.html` in your web browser
3. That's it! No installation or dependencies required

### Usage
1. **Add a Task**: Type your task in the input field and click "Add" or press Enter
2. **Complete a Task**: Click the checkbox next to a task to mark it as complete
3. **Delete a Task**: Click the trash icon to remove a task
4. **Filter Tasks**: Use the filter buttons to view:
   - All tasks
   - Active (incomplete) tasks
   - Completed tasks
5. **Clear Completed**: Click "Clear Completed" button to remove all finished tasks

## 💾 Local Storage

All your tasks are automatically saved to your browser's local storage. This means:
- ✅ Your tasks persist even after closing the browser
- ✅ No account or login required
- ✅ Your data stays on your device (privacy-friendly)
- ⚠️ Clearing browser data will delete your tasks

## 🐛 Known Limitations

- Maximum task length: 100 characters
- Local storage has size limits (~5-10MB per domain)
- Tasks are not synced across devices
